# A08 Agent 工作规则

## 用途与生命周期

- 适用与触发：必要；根规则与示例规则各自限定范围；首次初始化、工具/模块/验证规则变化。
- 生产者：人驱动的 AI；责任角色：仓库维护人。
- 输入：仓库定位、模块边界、项目约束、可用命令。
- 使用者与用途：任何进入仓库的新 Agent。
- 输出：项目内 `AGENTS.md`；实例、版本、来源及失效遵循[约定](../conventions.md)。
- 配套：[模板](../../templates/A08-agent-rules.md) · [教学填写示例](../../examples/focustask/docs/artifact-examples/A08-agent-rules.md)。

## 必填内容与字段含义

| 章节 | 必须回答 |
| --- | --- |
| 定位与目录 | 阶段、目标、模块职责和子目录适用范围 |
| 事实来源 | 必读文件、冲突优先级、任务入口 |
| 执行与决策 | 自主范围、必须升级问题、工作区保护 |
| 命令和质量 | 真实安装、开发、验证命令及UI条件 |
| 安全与交付 | 敏感数据、变更边界、职责分离、输出证据 |

元数据必须包含实例ID、版本、状态、责任角色、输入版本、确认来源、下游用途、未决项。字段未知标明原因；建议与事实分开。

## 质量标准与边界

新Agent能找到任务和命令、知道自主边界，未存在命令标尚未建立。区分根仓库与子项目范围，写真实命令与来源，不复制全部需求。规则变化先更新来源，相关测试/运行记录标为待重验，旧结果保留原适用版本。

- 不足示例：“你是资深工程师，写高质量代码”。
- 可判定示例：“开始先读 scope 与任务规格；权限规则缺失暂停相关实现；报告实际检查结果”。

## 人驱动 AI 的操作链

依[提示词协议](../practices/prompt-protocol.md)取得参数。开始时人提供目标与输入位置；AI先读取事实，缺关键规则才追问。选择/修订用真实人的反馈或既有授权，不要求每一步重新批准。只写本文需文件读写；验证/执行代码另需终端和目标环境，UI需浏览器。

### A08-START

```text
[A08-START] 请为 {项目} 的 {目标} 开始准备 A08 Agent 工作规则。先读取 {输入路径}：仓库定位、模块边界、项目约束、可用命令。区分根仓库与子项目范围，写真实命令与来源，不复制全部需求。列事实、缺口与下一步；可发现的事实直接核对，不重复问人。
```

### A08-CLARIFY

```text
[A08-CLARIFY] 请澄清 Agent 工作规则 的 {问题}。先读 {输入路径} 并说明冲突来源，给出会改变结果的选项和取舍。重点检查：新Agent能找到任务和命令、知道自主边界，未存在命令标尚未建立。未知关键规则暂停定案，已明确内容继续起草。
```

### A08-SELECT

```text
[A08-SELECT] 依据 {确认来源}，本轮对 Agent 工作规则 采用 {已选方案}，适用范围是 {目标}。请记录决定、来源、影响和未确认事项；先核对来源真实存在，再更新状态，不把建议写成人的批准。
```

### A08-GENERATE

```text
[A08-GENERATE] 请依据 {输入路径} 为 {目标} 生成 A08 Agent 工作规则，写入 {输出路径}，使用 templates/A08-agent-rules.md。区分根仓库与子项目范围，写真实命令与来源，不复制全部需求。逐章填写规范要求，未知和不适用说明原因；涉及运行结果必须来源于真实工具，未执行不得填通过；返回文件、版本和实际检查。
```

### A08-REVIEW

```text
[A08-REVIEW] 请按下游使用者的视角审阅 {制品路径}：任何进入仓库的新 Agent。检查 新Agent能找到任务和命令、知道自主边界，未存在命令标尚未建立。逐项给出位置、预期/实际、影响与建议，区分缺输入和内容错误；不直接改变已确认标准。
```

### A08-REVISE

```text
[A08-REVISE] 请根据 {反馈} 修订 {制品路径}，保留来源和版本关系。重点仍是：区分根仓库与子项目范围，写真实命令与来源，不复制全部需求。先列影响，再修改获准内容，同步关联制品并在 A16 标记需重验的证据；业务规则变化无确认来源时暂停相关改动。
```

### A08-VERIFY

```text
[A08-VERIFY] 请独立核对 {制品路径} 的候选 {候选}，依据 {输入路径} 与 A08 规范。验证 新Agent能找到任务和命令、知道自主边界，未存在命令标尚未建立。给出通过/失败/无法判定/阻塞，附步骤、环境、版本和证据；只读产品实现，不以生成者总结当结果。
```

### A08-HANDOFF

```text
[A08-HANDOFF] 请把 Agent 工作规则 交给下一执行者，保存到 {交接路径}。明确 任何进入仓库的新 Agent，记录输入/输出版本、真实检查、未决项及下一条指令。接手者应能只凭文件继续，涉及运行中的服务先标记需要复查状态。
```

### A08-FAILURE

```text
[A08-FAILURE] 处理生成或验证 Agent 工作规则 时发生的 {错误}。读取实际输出、当前版本和 A08 输入要求，判断是工具/环境、规格缺失还是实现问题。记录已尝试方案和影响；仅执行已授权的安全恢复，不放宽验收、不伪造结果。
```

## 完成、更新与交接

检查必填项、来源、质量标准和下游可用性；每次修改按版本更新，不覆盖旧确认历史。草稿完成不等于业务确认，候选验证不等于已发布。无证据的运行结论保持无法判定。交接给上述使用者，失败按 FAILURE 返回相关阶段。
