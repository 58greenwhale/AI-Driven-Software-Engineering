# A18 部署与回退指南

## 用途与生命周期

- 适用与触发：每个部署目标必要；可共享版本化脚本；首次部署目标、配置或兼容性变化。
- 生产者：人驱动的 AI；责任角色：技术/发布责任人。
- 输入：A04、A17、实际环境信息、迁移与兼容性。
- 使用者与用途：发布或维护 Agent，人工评估风险。
- 输出：项目内 `docs/deploy-rollback.md`；实例、版本、来源及失效遵循[约定](../conventions.md)。
- 配套：[模板](../../templates/A18-deploy-rollback.md) · [教学填写示例](../../examples/focustask/docs/artifact-examples/A18-deploy-rollback.md)。

## 必填内容与字段含义

| 章节 | 必须回答 |
| --- | --- |
| 目标与前置 | 目标地址、运行时、隔离数据库、产物与权限 |
| 部署步骤 | 按顺序准备、校验、迁移、启动、健康、冒烟 |
| 迁移与兼容 | 空库、已有库、重复执行、前后版本兼容 |
| 失败与回退 | 触发、停止范围、前版构建、配置、数据风险、恢复检查 |
| 清理与记录 | PID核对、证据保存、环境复位、何时不允许自动继续 |

元数据必须包含实例ID、版本、状态、责任角色、输入版本、确认来源、下游用途、未决项。字段未知标明原因；建议与事实分开。

## 质量标准与边界

步骤有前置、预期与失败分支，代码回退与数据恢复区别清楚。按目标环境定义发布和恢复，记录操作归属并保留已有数据。规则变化先更新来源，相关测试/运行记录标为待重验，旧结果保留原适用版本。

- 不足示例：“有问题回滚一下”。
- 可判定示例：“健康失败时停止本任务失败进程，重新启动上个已验证产物，验证旧任务ID和新增读写”。

## 人驱动 AI 的操作链

依[提示词协议](../practices/prompt-protocol.md)取得参数。开始时人提供目标与输入位置；AI先读取事实，缺关键规则才追问。选择/修订用真实人的反馈或既有授权，不要求每一步重新批准。只写本文需文件读写；验证/执行代码另需终端和目标环境，UI需浏览器。

### A18-START

```text
[A18-START] 请为 {项目} 的 {目标} 开始准备 A18 部署与回退指南。先读取 {输入路径}：A04、A17、实际环境信息、迁移与兼容性。按目标环境定义发布和恢复，记录操作归属并保留已有数据。列事实、缺口与下一步；可发现的事实直接核对，不重复问人。
```

### A18-CLARIFY

```text
[A18-CLARIFY] 请澄清 部署与回退指南 的 {问题}。先读 {输入路径} 并说明冲突来源，给出会改变结果的选项和取舍。重点检查：步骤有前置、预期与失败分支，代码回退与数据恢复区别清楚。未知关键规则暂停定案，已明确内容继续起草。
```

### A18-SELECT

```text
[A18-SELECT] 依据 {确认来源}，本轮对 部署与回退指南 采用 {已选方案}，适用范围是 {目标}。请记录决定、来源、影响和未确认事项；先核对来源真实存在，再更新状态，不把建议写成人的批准。
```

### A18-GENERATE

```text
[A18-GENERATE] 请依据 {输入路径} 为 {目标} 生成 A18 部署与回退指南，写入 {输出路径}，使用 templates/A18-deploy-rollback.md。按目标环境定义发布和恢复，记录操作归属并保留已有数据。逐章填写规范要求，未知和不适用说明原因；涉及运行结果必须来源于真实工具，未执行不得填通过；返回文件、版本和实际检查。
```

### A18-REVIEW

```text
[A18-REVIEW] 请按下游使用者的视角审阅 {制品路径}：发布或维护 Agent，人工评估风险。检查 步骤有前置、预期与失败分支，代码回退与数据恢复区别清楚。逐项给出位置、预期/实际、影响与建议，区分缺输入和内容错误；不直接改变已确认标准。
```

### A18-REVISE

```text
[A18-REVISE] 请根据 {反馈} 修订 {制品路径}，保留来源和版本关系。重点仍是：按目标环境定义发布和恢复，记录操作归属并保留已有数据。先列影响，再修改获准内容，同步关联制品并在 A16 标记需重验的证据；业务规则变化无确认来源时暂停相关改动。
```

### A18-VERIFY

```text
[A18-VERIFY] 请独立核对 {制品路径} 的候选 {候选}，依据 {输入路径} 与 A18 规范。验证 步骤有前置、预期与失败分支，代码回退与数据恢复区别清楚。给出通过/失败/无法判定/阻塞，附步骤、环境、版本和证据；只读产品实现，不以生成者总结当结果。
```

### A18-HANDOFF

```text
[A18-HANDOFF] 请把 部署与回退指南 交给下一执行者，保存到 {交接路径}。明确 发布或维护 Agent，人工评估风险，记录输入/输出版本、真实检查、未决项及下一条指令。接手者应能只凭文件继续，涉及运行中的服务先标记需要复查状态。
```

### A18-FAILURE

```text
[A18-FAILURE] 处理生成或验证 部署与回退指南 时发生的 {错误}。读取实际输出、当前版本和 A18 输入要求，判断是工具/环境、规格缺失还是实现问题。记录已尝试方案和影响；仅执行已授权的安全恢复，不放宽验收、不伪造结果。
```

## 完成、更新与交接

检查必填项、来源、质量标准和下游可用性；每次修改按版本更新，不覆盖旧确认历史。草稿完成不等于业务确认，候选验证不等于已发布。无证据的运行结论保持无法判定。交接给上述使用者，失败按 FAILURE 返回相关阶段。
