# 提示词操作协议

## 使用方式

提示词是人的操作入口。选定阶段/制品后先读输入，替换参数并执行；AI 应查询已有事实，给关键歧义提供选项。已有授权充分时可连续生成、检查、修订并交接，不要求人为重复每条指令。人也可只运行某一条审阅或恢复指令。

阶段提示词负责把工作串起来；制品提示词负责产出细节。模型不依赖隐藏的聊天历史、某个特定模型或第三方技能。

## 参数从哪里来

| 参数 | 获取方式 | 缺少时 |
| --- | --- | --- |
| {项目} | 项目目录或仓库根 | 先定位目录，不发明路径 |
| {目标} | 人的本轮目标、范围说明或变更单 | 澄清目标与成功条件 |
| {输入路径} | 制品目录、本阶段前驱、现有源码 | 先搜索读取，再列真实缺口 |
| {输出路径} | 项目约定或本类推荐位置 | 沿用已有模式，记录保守选择 |
| {制品路径} | 已生成的文档或代码路径 | 未生成时运行 GENERATE |
| {候选} | 提交、源码摘要或制品版本 | 先建立可复查标识，未提交也要含差异摘要 |
| {确认来源} | 真实用户选择或已确认范围 | 记待确认，不能伪造审批 |
| {已选方案}/{人的选择与来源} | 澄清步骤中人的真实反馈或计划已授权的选择 | 只列建议，不代人选择关键业务语义 |
| {反馈}/{问题}/{错误} | 人的反馈或实际工具结果 | 不预设失败；用实际内容 |
| {交接路径} | 项目 A13 存放位置 | 新建并记录版本和下一步 |

参数路径相对仓库根或明确的项目根；每次指令说明工作目录。教学实例中给定的路径需要先核对存在。规范/模板可以保留占位符，实际运行记录必须填写或标为未知。

阶段指令中更具体的参数（如验收依据、需求包版本、发布证据、确认方案、错误日志）均指该阶段输入表对应的制品实例与版本；执行者先查制品目录/任务表，不能凭参数名字发明一个已完成文档。具体命令不可执行时先补工程基线或报告阻塞。

## 操作链与输出

| 后缀 | 时机与输入 | 输出和完成判断 | 未完成时 |
| --- | --- | --- | --- |
| START | 新建/更新制品，目标与资料 | 当前事实、缺口、下一步可执行 | CLARIFY |
| CLARIFY | 关键输入缺失或冲突 | 按影响排序的问题、选项、默认建议及影响 | 等待关键决定；其他内容可继续 |
| SELECT | 人已作真实选择或授权可查 | 确认记录、适用边界、仍未决项 | 缺来源不得标已确认 |
| GENERATE | 输入达到进入条件 | 文件/实际操作、来源、检查结果 | FAILURE 或 CLARIFY |
| REVIEW | 有草稿或候选 | 按下游用途的发现清单和修订建议 | REVISE |
| REVISE | 反馈或已确认变更 | 更新制品、影响与证据失效清单 | 缺关键决定先澄清 |
| VERIFY | 指定标准与候选 | 逐项结论和实际证据 | A15 或 FAILURE |
| HANDOFF | 跨阶段或会话 | 可恢复的 A13 与下一条指令 | 缺版本/环境先补足 |
| FAILURE | 真实错误或执行能力缺失 | 原因、可行恢复、阻塞边界 | 安全替代或报告待处理 |

## 可连续执行的总指令

```text
[PROMPT-RUN] 请在 {项目} 为 {目标} 执行 {制品编号} 的操作链。
读取该制品规范、输入路径与模板，核对真实状态。
在已有确认和授权内生成/执行、审阅、修订并验证，保存实际结果。
只有新的关键业务决定或当前环境授权不足时才暂停相关动作并解释影响。
输出文件路径、版本、实际检查、未决项及下一阶段指令；不能用教学示例代替证据。
```

需要能力：只写规格时为文件读写；验证实现另需终端和测试环境；发布另需本地进程/数据库权限；UI另需浏览器。能力不足记录阻塞，不将“命令建议”写成“命令已运行”。

## FocusTask 已填参数示例

```text
[PROMPT-RUN / 教学填写示例] 请在 examples/focustask 为 TASK-001 创建任务执行 A03 操作链。
输入是 docs/product.md、docs/domain.md、docs/permissions.md、docs/architecture.md
和 docs/features/TASK-001-create-task.md。输出为同一功能规格的修订草稿。
保留原验收规则，区分原产品愿景和实施计划选定的本地实证切片。
新业务规则不要自行确认；给出可执行的测试映射和接下来生成 A07 的指令。
```

此段是教学示例，不能当作用户实际输入记录。实际使用时在 A21 写明来源为用户输入或依据授权的模板实例化，不保存隐藏推理和敏感信息。
