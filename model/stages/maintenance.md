# 维护与演进

## 进入、职责与输出

- 触发：技术故障、验证缺陷、新要求或需要恢复已知版本。
- 输入：运行版本、A19/A13、实际问题/新目标、现有规格和证据。
- 产出：[制品目录](../artifact-catalog.md)中的 A15问题/变更单、受影响A01–A18修订、A20维护报告与新发布证据。
- 人与AI分工：人确认新需求/风险取舍；AI复现、分析、提出最小修复、更新制品并执行验证；缺陷修复不改变原标准。
- 退出：原问题有同用例关闭证据，相关回归通过，必要再发布完成，数据保留，交接与追踪同步。
- 失败/返回：新语义回原型构建，数据/接口工程约束变化回原型重构，表现问题回原型精修；修复后重新审查；不能仅改文案隐藏失败。

## 执行步骤与提示词

下面每一条都可直接给AI执行。参数从本阶段输入和[提示词协议](../practices/prompt-protocol.md)取得；缺少参数先读取可发现事实，再澄清。已有授权足够时连续执行，不逐条重新索取批准。文件操作需要读写权限，运行/验证另需终端和对应环境；UI需要浏览器。

### MAINT-START：先建问题单

```text
[MAINT-START] 根据 {反馈或故障} 生成A15，标明来源是真实问题、需求变更或人为演练。读取运行版本和已有标准，记录现状、期望、影响与复现，不直接跳到改代码。
```

预期输出与判断：有版本和分类的问题/变更单。若条件不满足，使用 MAINT-RECOVER 或上文指定的返回路径。

### MAINT-DECIDE：诊断与影响分析

```text
[MAINT-DECIDE] 复现 {问题编号}，用实际日志/请求/数据解释原因。列可能影响的规格、接口、数据、测试、配置与证据，提出方案和代价；新业务语义依确认来源决定。
```

预期输出与判断：诊断依据与影响映射。若条件不满足，使用 MAINT-RECOVER 或上文指定的返回路径。

### MAINT-GENERATE：执行受控变更

```text
[MAINT-GENERATE] 按 {确认方案} 更新规格和追踪，再执行相关实现/迁移/测试。缺陷保持原确认的错误契约，本次需求变更新增独立用例；注入只在演练副本，不污染正常版本。
```

预期输出与判断：修订制品和修复候选。若条件不满足，使用 MAINT-RECOVER 或上文指定的返回路径。

### MAINT-REVIEW：评审变更传播

```text
[MAINT-REVIEW] 检查 {差异} 是否只覆盖问题范围，旧证据失效是否正确，所有关联规则与用例是否同步。向人解释残余风险和还未验证的部分。
```

预期输出与判断：评审与待重验清单。若条件不满足，使用 MAINT-RECOVER 或上文指定的返回路径。

### MAINT-VERIFY：回归和再发布

```text
[MAINT-VERIFY] 对 {新候选} 重跑原失败用例和影响回归，独立验证通过后按REL流程再发布。记录原数据、新操作和旧版本兼容情况，无日志不判关闭。
```

预期输出与判断：A20及对应发布运行证据。若条件不满足，使用 MAINT-RECOVER 或上文指定的返回路径。

### MAINT-HANDOFF：关闭与改进模型

```text
[MAINT-HANDOFF] 依据 {维护证据} 更新问题状态、交接和A22评价。指出哪些文档/提示词实际帮助或遗漏，修订模型后重试受影响步骤；保留未解决项。
```

预期输出与判断：关闭证据、改进与下一轮输入。若条件不满足，使用 MAINT-RECOVER 或上文指定的返回路径。

### MAINT-RECOVER：修复失败或回退

```text
[MAINT-RECOVER] 处理 {失败结果}，恢复已知版本并核对数据，记录尝试和限制。重新判断返回原型构建、重构、审查或精修中的哪项活动；不要反复无变化重试或偷偷放宽原验收。
```

预期输出与判断：可恢复状态与进一步决策。若条件不满足，使用 MAINT-RECOVER 或上文指定的返回路径。

```text
[MAINT-START / 已填参数示例] 从仓库根读取 examples/focustask/docs/context.md
及对应的 A01–A22 规范、模板与教学例。请填写 A15/A20 教学例，演示筛选变更或权限缺陷的影响、同类问题排查与回归计划。
只更新教学文档，不启动应用或数据库；不伪造确认、执行结果或发布身份。
若实际项目要执行本阶段，请先提供确认规格、固定候选、真实环境和授权。
```

## 交接出口

只有上文退出条件满足才进入[下一轮适用开发活动](../overview.md)。需要返工时在A15注明原因、影响、返回阶段和重验范围。对未执行项使用无法判定或阻塞；模板、候选自检和教学示例不能代替独立证据。
