# 实现与集成准备

## 进入、职责与输出

- 触发：一项范围明确、依赖满足的任务就绪；首次项目先完成工程基线。
- 输入：A03/A04/A05/A07/A08/A09/A10、工作区与确认决定。
- 产出：[制品目录](../artifact-catalog.md)中的 A11 源码/迁移/测试、A12 本地或PR评审、A13交接；A16持续更新。
- 人与AI分工：AI在授权内编码和修复；人处理新业务问题与不可逆取舍。评审由AI辅助，独立验收不由实现者自称完成。
- 退出：差异限定任务，自检与适用命令通过，测试对应AC，有候选版本与可恢复环境；此时进入待验收，不提前发布。
- 失败/返回：自检失败修复实现；契约矛盾返回设计；需求改变先A15；外部环境错误记录阻塞，不以删测试求绿。

## 执行步骤与提示词

下面每一条都可直接给AI执行。参数从本阶段输入和[提示词协议](../practices/prompt-protocol.md)取得；缺少参数先读取可发现事实，再澄清。已有授权足够时连续执行，不逐条重新索取批准。文件操作需要读写权限，运行/验证另需终端和对应环境；UI需要浏览器。

### IMP-START：选择就绪任务

```text
[IMP-START] 读取 {任务} 的规格与依赖及git状态。保护已有改动，列文件边界和验证方案。没有工程时按初始化指南建立A09；初始化输出命令不作为它自己的前提。
```

预期输出与判断：当前任务范围、边界和检查计划。若条件不满足，使用 IMP-RECOVER 或上文指定的返回路径。

### IMP-DECIDE：处理实现分歧

```text
[IMP-DECIDE] 对 {发现的问题} 核对既有契约和ADR；命名等局部细节按现有模式解决并记录。改变权限、数据或范围时给出选项等待必要决定；无关部分继续。
```

预期输出与判断：已确认决定或阻塞边界。若条件不满足，使用 IMP-RECOVER 或上文指定的返回路径。

### IMP-GENERATE：执行实现

```text
[IMP-GENERATE] 按 {任务规格版本} 实际编写代码、迁移与自动化测试，使用现有模块模式。覆盖服务端校验、权限、幂等和失败恢复，更新A16，禁止在正常路径留下演练后门。
```

预期输出与判断：真实A11实现包与可运行测试。若条件不满足，使用 IMP-RECOVER 或上文指定的返回路径。

### IMP-REVIEW：审阅和自检

```text
[IMP-REVIEW] 检查 {候选} 差异是否匹配AC；运行项目lint、typecheck、test、test:e2e、build及相关UI验证。记录退出码、环境和原始证据；修复发现并重跑受影响项。
```

预期输出与判断：A12自检/评审材料与真实结果。若条件不满足，使用 IMP-RECOVER 或上文指定的返回路径。

### IMP-VERIFY：确认可移交

```text
[IMP-VERIFY] 对 {候选} 核对规格、源码、测试及证据版本；用例通过要读取断言与实际运行结果。自检不足则修复，不把实现者复查当独立验收。
```

预期输出与判断：移交检查清单与剩余风险。若条件不满足，使用 IMP-RECOVER 或上文指定的返回路径。

### IMP-HANDOFF：移交独立验收

```text
[IMP-HANDOFF] 在 {交接路径} 写任务、AC、候选摘要、环境启停/数据准备、检查入口、未决项与证据。把任务置待验收，给VAL-START，不要求候选已经合并。
```

预期输出与判断：A13与只读验证输入。若条件不满足，使用 IMP-RECOVER 或上文指定的返回路径。

### IMP-RECOVER：失败恢复

```text
[IMP-RECOVER] 处理 {实际测试/构建错误}，先复现并定位是环境、实现还是规格问题。修复获准问题并重验；若需改变标准先A15，保留第一次失败证据。
```

预期输出与判断：修复或阻塞记录与新候选。若条件不满足，使用 IMP-RECOVER 或上文指定的返回路径。

## FocusTask 填写示例

教学案例：路由与server服务分离；Prisma仅在服务层；幂等唯一性由数据库保证；不使用固定登录用户，不把脚本返回0作为检查。

```text
[IMP-START / 已填参数示例] 请在 examples/focustask 开展实现与集成准备。
本轮目标按根目录实施计划1.1和示例实证范围；输入从该目录的docs、evidence和实际代码读取。
先核对当前阶段和前置条件，路由与server服务分离；Prisma仅在服务层；幂等唯一性由数据库保证；不使用固定登录用户，不把脚本返回0作为检查。
按本阶段操作链推进，在已有授权内执行，保存文件/结果/证据。
本段是可复制示例，实际运行时请在A21区分用户输入和模板实例化执行。
```

## 交接出口

只有上文退出条件满足才进入[验证](verification.md)。需要返工时在A15注明原因、影响、返回阶段和重验范围。对未执行项使用无法判定或阻塞；模板、候选自检和教学示例不能代替独立证据。
