# 独立验证

## 进入、职责与输出

- 触发：编码自检完成并形成明确候选；修订后按影响重验。
- 输入：已确认AC、设计/非功能、候选快照、A07策略、夹具和环境。
- 产出：[制品目录](../artifact-catalog.md)中的 A14逐项验收、A15缺陷、A16覆盖与失效、A12集成依据。
- 人与AI分工：人借助AI理解证据完整性和残余风险；验证者不能为适配实现放宽标准或修改产品实现。
- 退出：适用AC全部有版本匹配的通过证据，没有阻断缺陷，评审完成；才可集成并进入发布准备。
- 失败/返回：实现缺陷返回受影响开发活动并重新审查；标准缺失返回原型构建澄清；环境缺失为阻塞；修复后同AC重验及相关回归。

## 执行步骤与提示词

下面每一条都可直接给AI执行。参数从本阶段输入和[提示词协议](../practices/prompt-protocol.md)取得；缺少参数先读取可发现事实，再澄清。已有授权足够时连续执行，不逐条重新索取批准。文件操作需要读写权限，运行/验证另需终端和对应环境；UI需要浏览器。

### VAL-START：建立独立验证上下文

```text
[VAL-START] 只读 {候选} 与 {验收依据}，不要继承编码者对通过的判断。核对版本、环境、夹具和测试入口，先记录验证计划及不能执行的部分。
```

预期输出与判断：独立计划与环境核对。若条件不满足，使用 VAL-RECOVER 或上文指定的返回路径。

### VAL-DECIDE：处理标准缺失

```text
[VAL-DECIDE] 若 {AC/环境} 存在歧义，列来源与缺失事实；能从规格查到的直接引用。业务规则缺失转给责任人，不自行补标准；允许的不适用项需范围依据。
```

预期输出与判断：待决策或阻塞记录。若条件不满足，使用 VAL-RECOVER 或上文指定的返回路径。

### VAL-GENERATE：执行验收

```text
[VAL-GENERATE] 按A07与AC执行界面、API、数据库及质量检查，填写A14每项步骤、预期、实际、结论和证据。只读实现，测试环境夹具可依规范准备。
```

预期输出与判断：真实逐项验收报告。若条件不满足，使用 VAL-RECOVER 或上文指定的返回路径。

### VAL-REVIEW：解释发现

```text
[VAL-REVIEW] 审阅 {验收报告} 的证据是否支持结论，尤其角色、重试、数据变化与UI状态。将失败写成可复现A15，向人解释阻断程度和修复返回阶段。
```

预期输出与判断：缺陷单及证据缺口。若条件不满足，使用 VAL-RECOVER 或上文指定的返回路径。

### VAL-VERIFY：重验修复

```text
[VAL-VERIFY] 对 {修复候选} 运行原失败AC与影响回归，保留前一版失败记录；检查新源码摘要与证据。未执行项仍记无法判定/阻塞，不复用旧通过冒充新结果。
```

预期输出与判断：复验结果与适用版本。若条件不满足，使用 VAL-RECOVER 或上文指定的返回路径。

### VAL-HANDOFF：移交集成与发布

```text
[VAL-HANDOFF] 汇总 {指定候选} 的验收、评审、数据和风险；通过后给出集成和REL-START输入。仅记录实际本地/远端集成事实，不虚构PR或CI。
```

预期输出与判断：明确发布候选和完整A16。若条件不满足，使用 VAL-RECOVER 或上文指定的返回路径。

### VAL-RECOVER：环境或验证失败

```text
[VAL-RECOVER] 记录 {实际失败} 的命令、时间、环境与影响。先查目标服务是否存活，区分已知缺陷和无法运行；恢复测试环境后重试，不用实现修改掩盖验收失败。
```

预期输出与判断：可复现恢复或阻塞清单。若条件不满足，使用 VAL-RECOVER 或上文指定的返回路径。

## FocusTask 教学填写示例

本目录只有[教学上下文](../../examples/focustask/docs/context.md)，没有可运行候选或环境。以下指令只生成文档，不作通过结论。

```text
[VAL-START / 已填参数示例] 从仓库根读取 examples/focustask/docs/context.md
及对应的 A01–A22 规范、模板与教学例。请检查 AC-01–AC-13 与权限、幂等和界面规则的一致性，准备未执行验收报告。
只更新教学文档，不启动应用或数据库；不伪造确认、执行结果或发布身份。
若实际项目要执行本阶段，请先提供确认规格、固定候选、真实环境和授权。
```

## 交接出口

只有上文退出条件满足才进入[发布](release.md)。需要返工时在A15注明原因、影响、返回阶段和重验范围。对未执行项使用无法判定或阻塞；模板、候选自检和教学示例不能代替独立证据。
