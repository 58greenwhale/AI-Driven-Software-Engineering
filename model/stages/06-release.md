# 发布与本地运行验证

## 进入、职责与输出

- 触发：本版本选入功能已验证，有生产构建与目标环境，不依赖发布任务自身。
- 输入：A14/A16、候选源码、构建配置、A17/A18、发布范围授权，以及活动交接的A23版本与确认记录。
- 产出：[制品目录](../artifact-catalog.md)中的 版本化生产产物、A17清单、A18部署回退指南、A19运行记录。
- 人与AI分工：人决定发布范围与风险，AI提供go/no-go依据并执行已授权的本地发布；指南只描述直接本地操作，不要求外部生产资源。
- 退出：清单所指构建实际运行、健康与核心动作通过、数据重启保留、回退方案可执行、证据绑定版本。
- 失败/返回：已知阻断失败no-go；证据不齐无法判定；部署失败按A18恢复；需要修改实现时返回受影响开发活动（[构建](01-prototype-building.md)、[重构](02-prototype-refactoring.md)、[审查](03-prototype-review.md)或[精修](04-prototype-polishing.md)）；不要重建空数据库掩盖数据丢失。

## 执行步骤与提示词

下面每一条都可直接给AI执行。参数从本阶段输入和[提示词协议](../practices/prompt-protocol.md)取得；缺少参数先读取可发现事实，再澄清。已有授权足够时连续执行，不逐条重新索取批准。文件操作需要读写权限，运行/验证另需终端和对应环境；UI需要浏览器。

### REL-START：准备发布候选

```text
[REL-START] 读取 {发布范围}、{候选}、验收报告与本地环境，核对没有阻断缺陷。生成A17清单，记录源摘要、产物、配置名称、迁移和前版恢复入口。
```

预期输出与判断：候选与依赖完整清单。若条件不满足，使用 REL-RECOVER 或上文指定的返回路径。

### REL-DECIDE：判断发布条件

```text
[REL-DECIDE] 依据 {发布证据} 给go/no-go/无法判定及逐项理由。已知失败优先no-go；已有明确本地发布授权可执行，不请求重复确认；新风险取舍列给人决定。
```

预期输出与判断：真实决定依据与授权边界。若条件不满足，使用 REL-RECOVER 或上文指定的返回路径。

### REL-GENERATE：实际构建与部署

```text
[REL-GENERATE] 核对A18前置条件，构建 {版本} 的生产产物并存摘要；在专用本地服务应用迁移后启动，记录命令/PID/端口。不得操作用户已有数据库或把开发服务器当发布。
```

预期输出与判断：真实产物、服务与A19步骤记录。若条件不满足，使用 REL-RECOVER 或上文指定的返回路径。

### REL-REVIEW：检查上线后的结果

```text
[REL-REVIEW] 执行 {冒烟用例}，覆盖本项目已确认的核心旅程和适用的安全/健康条件。记录实际输出及适用的数据标识；有持久化时重启后核对数据仍存在，失败立即按指南处理。
```

预期输出与判断：发布行为与持久化证据。若条件不满足，使用 REL-RECOVER 或上文指定的返回路径。

### REL-VERIFY：核对发布身份与恢复能力

```text
[REL-VERIFY] 核对 {运行记录} 中源快照、构建摘要、配置与实际服务一致。验证迁移不重复应用及前版恢复路径；尚未演练的恢复动作如实标未验证。
```

预期输出与判断：A19结论及待演练项。若条件不满足，使用 REL-RECOVER 或上文指定的返回路径。

### REL-HANDOFF：交给维护

```text
[REL-HANDOFF] 把已发布版本、配置位置、数据库、服务启停、日志、已知风险、回退触发和数据验证方式写入A13。给MAINT-START与明确目标，不能只留一个URL。
```

预期输出与判断：可运行的维护交接。若条件不满足，使用 REL-RECOVER 或上文指定的返回路径。

### REL-RECOVER：发布失败与回退

```text
[REL-RECOVER] 依据 {失败日志} 判断是否需回退，执行A18限定的恢复。只切换本任务的已验证构建/配置，检查数据兼容，保留原任务ID并验证读写；不删除数据库求绿。
```

预期输出与判断：失败与恢复记录、新状态。若条件不满足，使用 REL-RECOVER 或上文指定的返回路径。

## FocusTask 教学填写示例

示例输入为 [FocusTask 教学上下文](../../examples/focustask/docs/context.md)。以下指令生成发布文档，运行类检查未执行，不作通过结论。

```text
[REL-START / 已填参数示例] 从仓库根读取 examples/focustask/docs/context.md
及对应的 A01–A28 规范、模板与教学例。请填写 A17/A18/A19 教学例，列出缺少候选、构建、环境时不能发布的原因。
只更新教学文档，不启动应用或数据库；不伪造确认、执行结果或发布身份。
若实际项目要执行本阶段，请先提供确认规格、固定候选、真实环境和授权。
```

## 交接出口

只有上文退出条件满足才进入[维护](07-maintenance.md)。需要返工时在A15注明原因、影响、返回阶段和重验范围。对未执行项使用无法判定或阻塞；模板、候选自检和教学示例不能代替独立证据。
