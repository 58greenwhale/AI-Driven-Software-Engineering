# 设计

## 进入、职责与输出

- 触发：需求已足够明确，准备消除接口、数据、技术或交互不确定性。
- 输入：A01–A03、现有代码与模块约束、风险、环境事实。
- 产出：[制品目录](../artifact-catalog.md)中的 A04 架构契约、A05 UI规格（适用时）、A06 ADR（重要决定）、A07 验证策略。
- 人与AI分工：人选择跨模块、不可逆、成本和业务风险取舍；AI用备选方案和原型/技术探针解释，局部细节依据既定约束自主决定。
- 退出：模块职责与接口一致，错误和安全路径明确，UI状态映射协议，数据迁移可行，重要风险有验证方法。
- 失败/返回：业务决定缺失返回需求；技术原型失败更换方案或说明阻塞；原型结果只证明探针范围。

## 执行步骤与提示词

下面每一条都可直接给AI执行。参数从本阶段输入和[提示词协议](../practices/prompt-protocol.md)取得；缺少参数先读取可发现事实，再澄清。已有授权足够时连续执行，不逐条重新索取批准。文件操作需要读写权限，运行/验证另需终端和对应环境；UI需要浏览器。

### DES-START：核对设计输入

```text
[DES-START] 读取 {需求版本}、架构约束和现有代码，建立AC到组件/接口的映射。标出数据一致性、权限、兼容和环境风险，以及需要验证的未知点。
```

预期输出与判断：输入映射与技术风险。若条件不满足，使用 DES-RECOVER 或上文指定的返回路径。

### DES-DECIDE：比较方案

```text
[DES-DECIDE] 针对 {重要设计问题} 给出最少复杂度的可行方案、代价和验证方式。需要时做隔离原型并保存观察；按 {选择及来源} 更新ADR，保留反面后果。
```

预期输出与判断：A06与方案依据，或待决定项。若条件不满足，使用 DES-RECOVER 或上文指定的返回路径。

### DES-GENERATE：形成契约与验证策略

```text
[DES-GENERATE] 生成A04接口/数据/安全契约、适用A05页面状态和A07风险测试映射。明确每个写请求的认证/校验/事务/错误，迁移升级与回退兼容；不要只画组件图。
```

预期输出与判断：具体契约、UI与测试策略。若条件不满足，使用 DES-RECOVER 或上文指定的返回路径。

### DES-REVIEW：核对交叉一致性

```text
[DES-REVIEW] 对 {设计包} 检查领域、权限、字段、接口错误、UI反馈与AC一致性。按 {反馈} 修订受影响内容；没有业务授权不更改产品语义。
```

预期输出与判断：冲突清单与设计修订。若条件不满足，使用 DES-RECOVER 或上文指定的返回路径。

### DES-VERIFY：验证可实施性

```text
[DES-VERIFY] 核对 {设计版本} 的进入实现条件。检查关键依赖、契约示例、迁移和测试方法；技术探针必须有实际结果，不凭可行性文字判定通过。
```

预期输出与判断：设计检查与探针证据。若条件不满足，使用 DES-RECOVER 或上文指定的返回路径。

### DES-HANDOFF：交给实现

```text
[DES-HANDOFF] 生成任务依赖与A13，列文件边界、契约、AC、检查命令、环境和已确认决定。下一步初始化A09或执行IMP-START；标出还未具备的工具。
```

预期输出与判断：A10、A13及明确就绪任务。若条件不满足，使用 DES-RECOVER 或上文指定的返回路径。

### DES-RECOVER：设计或依赖不可行

```text
[DES-RECOVER] 处理 {失败结果}，区分环境阻塞、技术取舍和业务缺口。仅在授权内调整局部设计，主要栈变化记录ADR，不能偷偷替换数据库或移除测试。
```

预期输出与判断：失败依据、替代方案及返回阶段。若条件不满足，使用 DES-RECOVER 或上文指定的返回路径。

## FocusTask 填写示例

教学案例：沿用FocusTask既有栈，记录需要的版本调整ADR；本地运行隔离端口和数据库，身份、成员、任务与健康接口在编码前定义。

```text
[DES-START / 已填参数示例] 请在 examples/focustask 开展设计。
本轮目标按根目录实施计划1.1和示例实证范围；输入从该目录的docs、evidence和实际代码读取。
先核对当前阶段和前置条件，沿用FocusTask既有栈，记录需要的版本调整ADR；本地运行隔离端口和数据库，身份、成员、任务与健康接口在编码前定义。
按本阶段操作链推进，在已有授权内执行，保存文件/结果/证据。
本段是可复制示例，实际运行时请在A21区分用户输入和模板实例化执行。
```

## 交接出口

只有上文退出条件满足才进入[实现](implementation.md)。需要返工时在A15注明原因、影响、返回阶段和重验范围。对未执行项使用无法判定或阻塞；模板、候选自检和教学示例不能代替独立证据。
