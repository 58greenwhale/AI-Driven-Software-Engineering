# A15 CHANGE-001：状态筛选

- 类型：已确认计划中的需求变更，不是缺陷修复。
- 来源：实施计划1.1及实证范围v0.2.0。
- 当前版本：v0.1.0无筛选；目标版本v0.2.0。
- 状态：完成。原v0.2候选因APP-06失败保留；rc2经独立复核、实际发布、筛选冒烟与回退/恢复验证通过。证据见examples/focustask/evidence/acceptance-v02.md及releases/v0.2.0-rc2/run.md。

## 新行为

项目任务列表增加有标签的状态选择器：全部、待处理、进行中、已完成。GET tasks可带status=todo/in_progress/done；缺省或空为全部，非法状态400。结果按既有updatedAt/id排序，total为筛选结果数。

选择变化写入URL，刷新与浏览器返回恢复选择。筛选无结果显示“没有符合条件的任务”与“清除筛选”；项目完全无任务沿用旧空态。Viewer与归档项目可筛选，不能写入。

创建任务仍固定todo；当前筛选不含todo时，保持筛选与URL，提示“任务已创建，但不符合当前筛选条件”。仅状态筛选，不增加负责人筛选、搜索、分页或状态编辑。

## 影响与取舍

改动A03列表行为、A04读接口、A05工具栏与状态、A07测试、A11实现、A16追踪及A17–A20发布维护记录。数据库schema不变；旧版可以读取新版本写入的数据，因此本次回退优先切换构建、保留数据库。

客户端避免旧请求覆盖新筛选结果；明确加载/失败与空结果区分。路由query非法时显示可恢复的错误并允许清除，不能悄悄显示与URL不一致的全部数据。
