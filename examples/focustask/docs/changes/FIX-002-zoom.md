# A15 FIX-002：真实200%缩放下日期输入被按钮区遮挡

类型：末轮验收发现的UI缺陷，保持原200%核心操作与无覆盖标准；不是范围变更。

预期：缩放后表单可滚动，当前编辑字段和提交按钮均可见且不重叠。
