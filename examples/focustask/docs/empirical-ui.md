# A05 实证页面范围与验收

版本：0.1；来源：原任务列表页面、设计系统及实证范围。保留原有可访问性和视觉约束；删除切片外的虚假入口。

## 页面与动作

- 登录：邮箱/密码、有标签、提交中、统一凭据错误、请求失败；成功到项目入口；登录后可退出。
- 项目入口：仅当前成员项目，加载/空/失败；点击项目打开任务列表。
- 任务列表：项目名、角色、只读标识、新建按钮（有权时）、任务数、任务行；显示状态/负责人/截止日期。
- v0.1没有搜索、筛选、详情页、设置或成员管理假入口；v0.2仅增加状态筛选及URL同步。
- 桌面创建用模态框，移动用全屏；title、负责人、日期、取消、创建。字段及错误沿用原AC；提交中禁重复和关闭。

## 状态与恢复

加载使用稳定占位；请求失败和空项目分开；空项目有权者可创建，Viewer无创建入口。网络/服务器错误保留创建内容并重试，同内容沿用幂等键。字段错误焦点到第一个错误。归档变为全局只读；权限移除关闭创建并刷新权限；非成员统一Not Found不泄露项目名。

v0.2筛选无结果独立显示清除筛选。创建不符合当前筛选不改变筛选，显示“任务已创建，但不符合当前筛选条件”。URL回退恢复状态，不伪造新任务。

## 视觉、键盘与证据

使用原设计令牌；1440×900、1024×768、768×1024、390×844均无非预期横向滚动/裁切。100字符标题、长项目名、同名成员、空字段可用。验证键盘、焦点、标签、对话框语义、Escape取消与未保存确认、200%缩放；移动软键盘不遮住当前字段。

每个视口拍加载/正常/空/失败/字段错误/Viewer/归档适用状态；v0.2补筛选空。用API/数据库验证权限和幂等，截图只作为UI证据。测试失败开关只在测试夹具或浏览器拦截中实现。
