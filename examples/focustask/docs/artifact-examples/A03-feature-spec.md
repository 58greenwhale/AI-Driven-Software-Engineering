## 元信息与范围

TASK-001；教学假设身份、项目和成员输入已提供；不实现邀请或修改状态。

## 用户故事与前置条件

Editor 在活动项目创建任务以分配工作；需会话有效且为项目成员。

## 输入与规则

title trim 后 1–100；assignee 可空或本项目成员；dueDate 不早于项目今天。

## 流程与数据变化

提交带 Idempotency-Key；Editor 权限校验通过后事务创建，返回 201，任务写入该项目并刷新可见；Viewer 不进入该流程。

## 异常与界面状态

网络失败保留输入；相同内容重试沿用键；归档返回 409 且关闭创建表单。

## 接口与关联页面

POST /api/v1/projects/:projectId/tasks；Viewer 403；非成员 404；未知伪造字段 400。

## 验收与测试映射

AC-08 响应丢失重试：相同 ID 和仅一条数据；集成测试加浏览器断网恢复。
