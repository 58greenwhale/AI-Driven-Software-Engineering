## 系统定位与边界

FocusTask 教学系统用于演示团队任务创建、查看和通知协作。系统包含任务与通知两个教学模块；不包含真实邀请、计费、支付、组织管理或生产部署。

## 外部系统与系统关系

教学系统假设身份与项目成员信息由外部前置输入提供，不实现身份提供方。通知只记录教学事件，不连接邮件、短信或推送服务。接口、事件和数据所有权待 A04/A28 确认。

## 跨模块旅程与关键流程

Editor 创建任务后，tasks 模块保存任务并产生“任务已创建”教学事件；notifications 模块读取事件并生成教学通知。任务创建失败时不得生成通知，恢复边界和幂等规则待 A02/A03/A04。

## 全局角色与不变量

Editor 可以创建任务，Viewer 只能查看；非成员不可发现项目。正式权限和数据一致性以 A02 为准，本例没有真实运行结果。

## 系统数据流与非功能摘要

教学数据从界面进入任务接口并持久化，再以教学事件进入通知模块。安全、性能、可用性和监控指标尚未确认，实际采用时由 A04/A07 定义。
