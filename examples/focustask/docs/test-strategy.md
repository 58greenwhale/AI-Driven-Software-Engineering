# A07 实证验证策略

版本：0.1；建立时尚未实现应用。测试判据提前定义，运行结果写evidence，不在此预填通过。

## 功能映射

| 规则 | 验证层与数据 | 判据 |
| --- | --- | --- |
| 登录/退出/过期/限流 | API+数据库，虚构四角色，错误密码 | 统一401、有限失败429、注销后无效，不打印秘密 |
| 项目隔离 | 两项目、成员/非成员、UI和API | 无身份401，非成员404，项目列表仅成员 |
| AC-01/02 | 浏览器创建+API+刷新数据 | 一条持久记录、正确字段、固定todo |
| AC-03/04 | 单元边界+浏览器+直接API | 空标题不发请求；101码点400，DB无新增 |
| AC-05/06 | 非成员负责人、非法日期和时区固定时钟 | 服务端400；日期不能归一化蒙混过关 |
| AC-07/08 | 双击、同键并发、响应丢失、重试、异内容 | 仅一条且同ID；异内容409；事务失败无部分记录 |
| AC-09/10 | Viewer直调API、非成员、UI | 403/404及DB无变化，不以入口隐藏代替 |
| AC-11 | 表单打开后夹具归档 | 409 PROJECT_ARCHIVED、关闭表单、只读且无新增 |
| AC-12 | 浏览器丢响应/网络失败后恢复 | 输入保留、同键重试最多一条 |
| AC-13及页面状态 | 四视口、键盘、200%、自动无障碍、浏览器语义树 | 焦点正确、无裁切/横滚，严重/关键扫描问题为0 |
| CHANGE-001 | 三状态夹具、URL回退、空筛选、创建后不符合 | 合法过滤、不丢URL状态、空与错误区分 |
| 维护回退 | 真生产构建、同一发布数据库 | 旧记录存在、读取和新建正常，禁止重置数据库 |

## 工程命令

应用建立后实际运行lint、typecheck、test、test:e2e、build。单元用Vitest，API/数据库集成使用专用PostgreSQL，浏览器用Playwright。初始化前不存在命令记未具备；空检查脚本不算满足要求。

## 非功能适用性（运行前确定）

| 原要求 | 本地实证方法/范围 | 说明 |
| --- | --- | --- |
| 首屏P95≤2.5s、API P95≤500ms、筛选≤1s、CLS≤0.1、JS≤250KB | 生产构建、500任务/20成员；20次页面与100次创建，保存原始时间/体积 | 保留指标；本机CPU/内存/网络若不同必须报告，不能宣称达成指定硬件基线 |
| 安全、事务、幂等、敏感日志 | API与数据库验证、依赖审计、构建与日志检查 | Critical/High可利用漏洞仍阻止发布；授权不能豁免数据安全 |
| 可访问性 | 四视口/键盘/200%、自动扫描及浏览器可访问结构 | 如需真实辅助技术而环境不支持，单列未验证，不冒充全WCAG认证 |
| 最近两版浏览器、iOS/Android | 本地可运行Chromium/Firefox/WebKit及设备布局模拟 | 本次是本地流程实证；不能把WebKit模拟称为真实iOS或两代实机验证，完整产品兼容性保留为外部验证范围 |
| 月度99.5%可用性、30天备份/季度演练 | 本地发布健康、重启数据、备份/恢复演练 | 时间跨度指标不适用本次短时本地实证，不声称达到生产SLA |
| HTTPS生产与Cookie Secure | 区分仅回环HTTP实证配置与HTTPS部署配置 | 验证安全配置不能泛化到真实公网部署 |
| 监控告警长期指标 | 验证结构化请求记录、数据库健康；本地受控失败记录 | 值班/外部告警平台非本地切片交付目标，缺失不得说已经接入 |
| 服务端请求超时≤10秒 | 服务访问故障/慢响应，测量超时与可识别错误；配置数据库语句和请求处理上限 | 保留上限，不能无限等待外部依赖 |
| 320px–1920px宽度 | 在既定四视口外补320×844和1920×1080布局检查 | 无横向滚动、裁切和覆盖，不能只测四个点替代完整声明 |

以上按已确认“本地模拟实证”范围区分可观察与生产环境要求；功能AC与安全判据不因本地运行降低。实际数值或环境不足形成限制/无法判定记录，不在结果出来后放宽指标。

## 证据与重验

每次记录候选源摘要、规格版本、工具版本、夹具、命令、退出码、时间及脱敏原始输出。后续代码/依赖/环境变更标影响项失效，重跑相关检查。独立验收只读实现；人为Viewer故障只存在演练副本。

验证执行改进（实测后保留教训）：build与typecheck共享.next生成文件，须顺序执行。200%等效布局以外，补充隔离Chromium扩展API设置真实浏览器缩放2.0并完成登录/创建，记录实际zoom及viewport，不将其扩展为全设备辅助技术验证。
