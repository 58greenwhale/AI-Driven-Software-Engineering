# FocusTask 教学上下文

> 版本：teaching-1。用途：A01–A22 填写示例的共同输入，不是已实现产品、用户批准或实际运行记录。本目录没有应用或数据库，不提供可运行账号。

## 范围与术语

演示小团队在项目中创建和查看任务，以及增加状态筛选后的需求、设计与验证变化。`teaching-base` 表示创建/查看场景，`teaching-filter` 表示筛选变更；它们不是实际发布版本。

登录身份、项目和成员作为教学前置条件；不实现注册、邀请、项目创建、任务编辑、状态修改、批量操作、通知或归档管理。归档和权限变化可作为未来测试夹具输入，不代表存在管理界面。

User 为用户，Project 为项目，Membership 为用户在项目中的角色，Task 属于一个项目。项目状态为 active/archived，任务状态为 todo/in_progress/done。创建任务固定为 todo；本例不定义状态修改流程。

## 角色与权限

| 身份/状态 | 查看任务 | 创建任务 | 接口预期 |
| --- | --- | --- | --- |
| 未登录 | 不允许 | 不允许 | 401 |
| Admin / Editor | 允许 | 活动项目允许 | 创建成功 201 |
| Viewer | 允许 | 不允许，不显示新建入口 | 403，无数据变化 |
| Non-member | 不允许 | 不允许 | 404，不暴露项目是否存在 |
| 归档项目成员 | 只读 | 所有角色均不允许 | 409 PROJECT_ARCHIVED |

每次写请求及幂等重试都重新检查身份、成员资格、操作权限和项目状态。隐藏按钮不能代替服务端授权；错误响应不得泄露内部路径、凭据或堆栈。

## 字段、时间与一致性

| 字段 | 规则 |
| --- | --- |
| title | 必填字符串，trim 后按 Unicode 码点计数 1–100；不合并内部空格 |
| assigneeId | 可空；非空时为本项目成员；缺省规范化为 null |
| dueDate | 可空；有效 YYYY-MM-DD，不能早于项目时区今天；示例时区 Asia/Shanghai |
| status | 服务端固定 todo，客户端不得写入 |
| createdBy / projectId | 分别来自当前会话和路径，不接受正文伪造 |
| id / createdAt / updatedAt / version | 服务端生成；UUID 标识，时间戳使用 UTC；日期字段不按 UTC 改写 |

仅接受 title、assigneeId、dueDate，其他未知字段返回 400。成员下拉按显示名、邮箱升序排列。无效日期不得被日期库静默归一化。

创建使用 UUID `Idempotency-Key`，作用域为当前用户和项目。相同键与相同规范化内容返回首次 Task 和 201，只产生一条记录；同键不同内容返回 409。任务与幂等记录同事务写入，唯一约束处理并发。

内容改变或成功后换新键；响应丢失、网络重试保持原键。重试已成功请求时仍重新授权，但不因跨过午夜重新将原日期判成过去日期；新增写入才重新检查当天日期与负责人有效性。

## 接口与正常流程

以下路径是教学目标项目的接口设定，不是本仓库正在提供的服务。

| 接口 | 预期输入和输出 |
| --- | --- |
| GET /api/v1/projects/:projectId/tasks | 200，data 中含 tasks 数组及 total；空列表为 [] 和 0 |
| POST /api/v1/projects/:projectId/tasks | 三个业务字段及幂等键；201，data 为服务端 Task |
| GET /api/v1/health | 将来工程验证可用的应用/数据库健康检查；数据库故障预期 503，不泄露连接配置 |

响应示例：成功 `{data: ...}`；失败 `{error:{code,message,fields?,requestId}}`。字段错误 400，未登录 401、Viewer 403、非成员/不存在 404、归档或幂等冲突 409；失败不新增任务。

用户打开任务列表，选择新建，填写字段，客户端初检后提交。服务端完成校验及事务后返回 Task；页面使用服务端数据更新列表，关闭表单，显示成功提示并把焦点还给新建按钮。刷新后仍应能读取同一任务。

列表按 updatedAt 倒序、id 稳定排序。筛选场景增加 status 查询及 URL 同步：缺省或空为全部，合法值 todo/in_progress/done，其他值 400。筛选不改数据；total 为当前筛选数量。创建结果不符合筛选时保持筛选，提示“任务已创建，但不符合当前筛选条件”。不添加分页或搜索功能。

## 界面、异常与可访问性

- 列表展示项目名、角色、只读标识、任务数及标题、状态、负责人、截止日期；长文本可换行。
- 加载使用稳定占位；空项目、筛选无结果和请求失败分别展示，后两者提供清除筛选或重试。
- 桌面创建使用模态框，移动端全屏；包含标题、负责人、日期、取消和创建，不出现无实现依据的入口。
- 打开焦点到标题；字段失败聚焦第一个错误，保留其他合法输入；成功返回原入口。键盘可操作，标签、错误及对话框语义可识别。
- 提交中禁重复提交、字段编辑和关闭；网络/服务器错误保留输入并重试。取消、Escape 与未保存确认只用于非提交中状态。
- 权限被撤销或项目归档后，拒绝写入、关闭表单并刷新权限/只读状态；非成员页面不泄露项目名。
- 检查视口 1440x900、1024x768、768x1024、390x844，及 200% 缩放、软键盘、100 字符标题、长项目名、同名成员、空字段。不得出现重叠、裁切或非预期横向滚动。

## 工程与质量设定

教学架构采用 Next.js/React/TypeScript、PostgreSQL/Prisma；页面与 Route Handler 处理交互/协议，server 服务负责身份、权限、校验与事务，页面不直接访问数据库。版本要由实际项目核验并锁定，本仓库不声明已安装或提供此应用。

拟议验证层次为单元、API/数据库集成、浏览器 E2E；lint/typecheck/test/test:e2e/build 仅是未来项目应建立的命令类型，不是本目录的可运行命令。权限和幂等要观察响应及数据库，截图仅证明界面。

性能教学目标：生产构建、4 核/8 GB、500 条任务及 20 名成员，网络往返 100ms、下行 10 Mbps；列表首屏 P95 不超过 2.5 秒（20 次），创建 API P95 不超过 500ms（100 次、不计网络），筛选不超过 1 秒，CLS 不超过 0.1。未测量不填通过。

写请求重新授权并检查来源；会话 Cookie 使用 HttpOnly、适用的 SameSite/Secure，密码采用慢哈希；日志不含秘密。服务失败可识别且超时不超过 10 秒。测试只用虚构数据；不要把本地 HTTP 设置当作真实生产安全验证。
