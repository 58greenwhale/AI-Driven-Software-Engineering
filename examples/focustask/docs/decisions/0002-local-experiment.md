# ADR-0002：本地实证切片与直接运行

- 状态：依据用户已确认计划实施。
- 来源：实施计划1.1；用户明确“不用docker，发布和维护可以直接在本地操作”。
- 责任角色：项目所有者；本记录由执行者整理，不虚构人工审批。

## 背景与选择

全产品MVP过大，不是模型实证目标。使用登录、预置项目、创建/查看任务形成v0.1，状态筛选形成v0.2。保留原创建AC和安全规则。项目/成员管理使用夹具，不冒充已实现功能。

原方案本地容器需要额外环境；用户已选择直接本地运行。采用任务专用进程、端口、数据目录/数据库和版本化生产构建；不重用或重置用户已有5432服务。必须记录PID归属、迁移与数据兼容，再验证回退。

## 契约澄清

原架构“忽略并拒绝”伪造字段矛盾，按禁止伪造的严格约束选择400拒绝未知写字段。状态筛选未知值按已有字段校验约定返回400；缺省/空为全部。标题按Unicode码点计算避免代理对长度不一致。这些是既定规则内的明确化，不新增权限或计费语义。

## 后果与复评

本地验证不能证明生产SLA、实机浏览器和公网安全。依赖/运行时主要版本若调整，另记技术ADR和实际兼容测试。加入新产品功能或真实生产目标需新范围决定，不能从本次授权推导。
