# FocusTask 设计系统

> 迁移说明：保留的 FocusTask 产品规格输入；本地实证仅覆盖选定切片，范围与状态以 [实证范围](empirical-scope.md) 和 [实证任务表](iteration-plan.md) 为准。本文不是功能已实现的证明。

## 1. 设计目标

界面应安静、清晰、适合频繁操作。优先展示任务内容和当前状态，不使用营销式大标题、装饰性卡片或与操作无关的动画。

## 2. 设计令牌

### 颜色

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 页面背景 | `#F7F8FA` | 页面底色 |
| 内容背景 | `#FFFFFF` | 表格、弹窗和输入区域 |
| 主文本 | `#17202A` | 标题和正文 |
| 次要文本 | `#667085` | 辅助信息，不用于关键错误 |
| 边框 | `#D0D5DD` | 控件和分隔线 |
| 主操作 | `#176B5B` | 主要按钮、选中状态和可访问焦点 |
| 主操作悬停 | `#125548` | 主要按钮悬停 |
| 危险 | `#B42318` | 破坏性操作和错误 |
| 警告 | `#B54708` | 需要注意但未失败的状态 |
| 成功 | `#067647` | 完成和成功反馈 |

文字与背景的对比度应至少达到 WCAG 2.2 AA。颜色不能作为状态的唯一表达方式，必须配合文本或图标。

### 字体

- 字体族：`Inter, "PingFang SC", "Microsoft YaHei", sans-serif`；
- 页面标题：24px / 32px，字重 600；
- 区域标题：18px / 26px，字重 600；
- 正文：14px / 22px，字重 400；
- 辅助文字：12px / 18px，字重 400；
- 字间距为 0，不随视口动态缩放字号。

### 间距与形状

- 间距基准为 4px，常用间距：4、8、12、16、24、32px；
- 表单字段间距为 16px；
- 卡片和弹窗圆角为 8px，按钮和输入框圆角为 6px；
- 桌面内容最大宽度为 1280px；
- 点击或触摸目标最小尺寸为 44×44px。

## 3. 响应式断点

| 名称 | 范围 | 行为 |
| --- | --- | --- |
| Mobile | `< 768px` | 单列布局，导航收进菜单 |
| Tablet | `768–1023px` | 保留紧凑侧栏或抽屉，内容自适应 |
| Desktop | `>= 1024px` | 固定侧栏和完整工具栏 |

不得只为单一设备宽度编码。页面应在 320px 至 1920px 范围内保持可用。

## 4. 基础组件

### 按钮

- 一个区域最多一个主要按钮；
- 图标可明确表达含义时使用图标按钮，并提供可访问名称和悬停提示；
- 提交期间显示处理中状态并阻止重复点击；
- 破坏性操作使用危险样式，并在不可恢复时二次确认。

### 表单

- 标签显示在输入控件上方；
- 必填项用文字或一致标记说明；
- 错误提示位于字段下方并说明如何修正；
- 提交失败后保留有效输入和用户焦点；
- 不只依赖 placeholder 表达字段含义。

### 弹窗与抽屉

- 桌面端创建任务使用最大宽度 520px 的弹窗；
- 移动端使用占满可用宽度的底部抽屉或全屏表单；
- 打开后焦点移到标题或第一个字段；
- 关闭后焦点返回触发按钮；
- 有未提交修改时，关闭操作需要确认。

### 任务列表

- 桌面端采用紧凑表格或列表行，不把每条任务包装为大型装饰卡片；
- 移动端隐藏低优先级列，将任务信息按两行排列；
- 行高固定，异步状态和长文本不能引起整体跳动；
- 状态使用文本标签和颜色共同表示。

## 5. 通用页面状态

- 加载：在内容位置显示骨架或进度，不清空已有内容进行短暂刷新；
- 空数据：说明当前没有内容，并提供用户有权限执行的下一步；
- 错误：说明操作失败，提供重试；不要暴露堆栈信息；
- 成功：就近更新内容；仅在结果不明显时显示短暂通知；
- 无权限：说明用户不能访问或执行操作，不展示无效控件；
- 离线：保留未提交输入并说明网络恢复后可重试。

## 6. 动效

- 普通状态变化为 120–200ms；
- 动效只用于表达状态和空间关系；
- 尊重 `prefers-reduced-motion`；
- 不使用循环装饰动画；
- 动画不得阻止用户继续操作。

## 7. 可访问性

- 使用语义化 HTML；
- 键盘顺序与视觉顺序一致；
- 所有可交互元素具有清晰焦点样式；
- 表单错误通过 `aria-describedby` 或等效机制关联；
- 弹窗正确管理焦点并支持 Escape 关闭；
- 动态成功或错误消息通过适当的 live region 通知；
- 支持浏览器放大至 200% 后完成核心流程。

## 8. 视觉验收

- 检查 `1440x900`、`1024x768`、`768x1024` 和 `390x844`；
- 不得出现元素重叠、被裁切、意外横向滚动或文字溢出；
- 截图必须覆盖正常、加载、空数据、错误和无权限状态；
- 键盘、鼠标和触摸均能完成核心操作。
