# FocusTask Example Rules

本目录是生命周期模型的实证，不是原产品全部 MVP。先读 docs/empirical-scope.md、iteration-plan.md、test-strategy.md 和相关业务规格、契约、ADR。根模型规则继续适用。

应用位于 app/；在该目录运行真实 npm 脚本，数据与服务只使用本任务专用目录/端口。发布维护直接在本地执行，无需 Docker。不得重置用户已有 PostgreSQL 服务或把开发服务器当发布版本。

规格/教学实例与 evidence 的真实记录严格区分。保留创建任务原 AC-01–13；预置用户/项目/成员不代表已实现邀请或项目创建。源代码、测试、构建与运行结果需绑定候选摘要。

UI覆盖四个指定视口和适用状态；权限通过API和数据库验证。故障注入只在隔离副本，独立验收只读正常实现。更新行为时同步规格、测试和A16。
