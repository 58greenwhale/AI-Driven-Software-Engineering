# 术语表

| 术语 | 定义 | 说明或反例 |
| --- | --- | --- |
| 用户（User） | 拥有 FocusTask 账户并可登录的人 | 未接受邀请的人仍可有用户账户，但不一定属于某个项目 |
| 项目（Project） | 一组围绕共同目标组织的任务和成员 | 项目不是团队或组织；MVP 不单独建立团队实体 |
| 项目成员（Project Member） | 已加入某个项目并具有项目角色的用户 | 仅收到邀请但尚未加入的人不算项目成员 |
| 项目管理员（Admin） | 可管理项目信息、成员、角色和归档状态的项目成员 | 不是系统管理员；权限仅限所属项目 |
| 编辑者（Editor） | 可在所属项目中创建和修改任务的成员 | 不能管理成员或归档项目 |
| 只读成员（Viewer） | 只能查看所属项目和任务的成员 | 不能通过界面或 API 修改任务 |
| 任务（Task） | 项目内可分配、可设截止日期并可更新状态的工作项 | MVP 不支持子任务 |
| 负责人（Assignee） | 当前负责完成任务的项目成员 | 负责人可以为空，但不能是项目外用户 |
| 创建人（Creator） | 首次创建任务的用户 | 后续修改任务时创建人不改变 |
| 待处理（Todo） | 任务已经创建但尚未开始的状态 | 数据值为 `todo` |
| 进行中（In progress） | 任务正在执行的状态 | 数据值为 `in_progress` |
| 已完成（Done） | 任务工作已经完成的状态 | 数据值为 `done`，可重新打开 |
| 归档（Archived） | 项目不再活跃并进入只读状态 | 归档不是物理删除，项目数据仍保留 |
| 验收用例（Acceptance Criterion） | 可以通过操作和结果判断功能是否符合要求的规则 | 不能只写“体验良好”等主观结论 |
| MVP | 首个可交付版本的范围 | 只包含 `product.md` 明确列出的 MVP 项目 |
