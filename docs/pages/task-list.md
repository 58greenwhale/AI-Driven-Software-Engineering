# 页面规格：项目任务列表

## 1. 页面信息

- 路径：`/projects/:projectId/tasks`
- 主要功能：查看、筛选和创建任务；
- 关联功能：`docs/features/TASK-001-create-task.md`；
- 允许访问：当前项目的 Admin、Editor 和 Viewer；
- 页面标题：项目名称；
- 浏览器标题：`{项目名称} · FocusTask`。

## 2. 信息层级

从上到下依次为：

1. 全局导航；
2. 项目标题、项目状态及主要操作；
3. 项目内导航；
4. 筛选与结果数量；
5. 任务列表；
6. 分页或加载更多区域。

不得在任务列表上方增加与任务无关的营销内容、统计大卡片或装饰区块。

## 3. 桌面布局（>= 1024px）

```text
┌──────────────┬──────────────────────────────────────────────────┐
│ FocusTask    │ 网站改版                         [新建任务]       │
│              │ 任务   成员   设置                                │
│ 项目列表     ├──────────────────────────────────────────────────┤
│ - 网站改版   │ [状态 ▾] [负责人 ▾] [搜索任务____________]        │
│ - 发布计划   │                                                  │
│              │ 12 条任务                                        │
│              │ ○ 确认首页文案   待处理   陈晓   09-21           │
│              │ ◐ 完成视觉稿     进行中   林青   09-23           │
│              │ ● 上线检查       已完成   未分配  无截止日期      │
└──────────────┴──────────────────────────────────────────────────┘
```

- 左侧导航宽度 240px，页面滚动时保持可用；
- 主内容左右内边距 32px，最大宽度 1280px；
- 标题和“新建任务”在同一行；
- 筛选栏使用稳定列宽，不因加载文本变化而跳动；
- 列表行高度至少 56px。

## 4. 平板布局（768–1023px）

- 左侧导航收为 72px 图标栏或抽屉；
- 主内容左右内边距 24px；
- 标题和主要操作仍保持可见；
- 任务列表隐藏创建人等非核心字段；
- 筛选控件空间不足时允许换行，不得覆盖列表。

## 5. 移动布局（< 768px）

```text
┌──────────────────────────┐
│ [菜单] 网站改版      [+] │
│ 任务  成员                │
├──────────────────────────┤
│ [筛选] [搜索___________]  │
│ 12 条任务                 │
│                          │
│ 确认首页文案              │
│ 待处理 · 陈晓 · 09-21     │
├──────────────────────────┤
│ 完成视觉稿                │
│ 进行中 · 林青 · 09-23     │
└──────────────────────────┘
```

- 页面左右内边距 16px；
- “新建任务”使用带可访问名称的加号图标按钮；
- 任务信息采用两行布局；
- 长标题最多两行，不能覆盖状态信息；
- 页面不能出现非预期横向滚动；
- 创建任务使用全屏表单或底部抽屉，宽度不超过视口。

## 6. 任务行

桌面字段顺序：

| 字段 | 宽度或行为 |
| --- | --- |
| 状态图标 | 固定 32px，具备文本替代 |
| 标题 | 弹性宽度，最多两行 |
| 状态 | 固定 96px，文本加颜色标签 |
| 负责人 | 120px，空值显示“未分配” |
| 截止日期 | 112px，空值显示“无截止日期” |

- 点击标题或任务行主要区域进入详情；
- 行内操作不能嵌套在进入详情的链接中；
- 过期日期使用危险色并显示“已逾期”；
- 今日到期显示“今天”；其他日期按当前语言环境展示，但可访问名称包含完整日期。

## 7. 筛选和搜索

- 状态：全部、待处理、进行中、已完成；
- 负责人：全部、分配给我、未分配和项目成员；
- 搜索：匹配任务标题，输入停止 300ms 后更新；
- 筛选条件同步到 URL query，例如 `?status=todo&assignee=me&q=首页`；
- 从详情返回列表时恢复筛选和滚动位置；
- 清除筛选后显示全部任务；
- 筛选结果为空和项目本身无任务使用不同文案。

## 8. 页面状态

### 首次加载

- 标题区域可用时先显示；
- 列表显示 6 行固定高度骨架；
- 骨架不能模拟真实文字，也不能导致完成加载时大幅跳动；
- “新建任务”在权限未确认前不显示。

### 正常数据

- 显示结果数量和任务列表；
- 默认按 `updatedAt` 倒序；
- 同一时间戳按任务 `id` 稳定排序。

### 项目无任务

- 标题：“还没有任务”；
- Admin/Editor 说明：“创建第一条任务，开始安排项目工作。”并显示“新建任务”；
- Viewer 说明：“该项目暂时没有任务。”且不显示创建入口。

### 筛选无结果

- 标题：“没有符合条件的任务”；
- 提供“清除筛选”按钮；
- 不显示“新建任务”作为主要解决方案。

### 加载失败

- 列表区域显示“任务加载失败”；
- 显示“重试”按钮；
- 页面标题和导航保持可用；
- 不把请求失败错误显示成空数据。

### 无权限或资源不存在

- 返回统一的 Not Found 页面；
- 不显示项目名称、成员或任务数量；
- 提供返回项目列表入口。

### 归档项目

- 标题旁显示“已归档”；
- 页面顶部显示“该项目已归档，只能查看”；
- 隐藏创建和所有写操作；
- 保留筛选、搜索和查看详情能力。

## 9. 创建任务表单

### 桌面

- 使用宽度 520px 的模态框；
- 标题为“新建任务”；
- 字段顺序：任务标题、负责人、截止日期；
- 底部操作：次要按钮“取消”，主要按钮“创建任务”。

### 移动

- 使用全屏表单；
- 顶部包含返回按钮和“新建任务”标题；
- 底部操作区域在软键盘关闭时固定可见，但不得遮挡字段；
- 打开软键盘后，当前字段必须能滚动到可见区域。

### 交互

- 打开后焦点进入标题字段；
- Escape 或取消关闭空白表单；
- 有修改时取消或关闭，询问“放弃未保存的内容？”；
- 提交状态、错误处理和成功行为遵循功能规格；
- 成功后焦点返回打开表单的按钮。

## 10. 可访问性

- 页面包含一个 `h1`，内容为项目名称；
- 项目内导航使用可识别的导航区域；
- 筛选控件具有可见标签或明确的可访问名称；
- 任务列表使用语义合适的列表或表格；
- 状态不能只通过图标形状或颜色表达；
- 加载完成、筛选结果数量和创建结果适度通知屏幕阅读器；
- 模态框符合对话框语义并管理焦点；
- 所有目标尺寸至少 44×44px。

## 11. UI 验收清单

- [ ] `1440x900`：侧栏、标题、筛选和全部列表列正确显示；
- [ ] `1024x768`：内容无裁切，工具栏保持可操作；
- [ ] `768x1024`：紧凑导航和筛选换行无重叠；
- [ ] `390x844`：单列任务行、图标按钮和全屏表单可用；
- [ ] 200% 缩放：核心操作可完成；
- [ ] 长项目名、100 字符任务标题和同名成员不破坏布局；
- [ ] 加载、正常、项目空、筛选空、失败、无权限和归档状态均有截图；
- [ ] Admin、Editor 和 Viewer 的界面权限符合矩阵；
- [ ] 只使用键盘能够筛选、打开和创建任务；
- [ ] 无严重或关键自动化无障碍问题。

## 12. 测试数据

验收环境至少准备：

- Admin、Editor、Viewer 和 Non-member 各一个账户；
- 一个空项目；
- 一个含 20 条任务的项目；
- 包含短标题、100 字符标题、未分配、今天到期、已逾期和三个任务状态；
- 一个归档项目；
- 一个接口稳定失败的测试开关，用于验证错误和重试状态。
