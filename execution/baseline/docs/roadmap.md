# MVP 实施路线图

## 状态说明

- `待决策`：存在阻止实施的产品或技术问题；
- `就绪`：规格和依赖已经满足；
- `进行中`：正在实现；
- `待验收`：实现完成，等待独立验收；
- `完成`：通过完成标准；
- `阻塞`：外部条件导致无法继续。

## 路线图维护规则

- 任务进入“就绪”前必须具备可判定的验收用例；
- 实现开始时由执行者更新为“进行中”；
- 编码完成且自测通过后更新为“待验收”；
- 只有独立验收通过后才能更新为“完成”；
- 需求变化必须同时更新对应规格和依赖关系。
