# FocusTask 产品总纲

## 1. 产品定位

FocusTask 是面向 2–20 人小型团队的轻量任务管理工具。它帮助团队把零散工作集中到项目中，明确任务负责人、截止日期和完成状态。

## 2. 要解决的问题

- 任务散落在聊天记录和个人笔记中，难以统一查看；
- 团队成员不清楚任务由谁负责、何时完成；
- 复杂项目管理工具配置成本高，不适合小团队快速开始。

## 3. 目标用户

### 项目负责人

创建项目、邀请成员、拆分任务并追踪完成情况。

### 项目成员

查看分配给自己的任务，更新任务状态，并了解项目当前进展。

## 4. 核心场景

1. 项目负责人在 5 分钟内创建项目并添加首批任务。
2. 成员登录后能够立即看到自己负责的未完成任务。
3. 成员完成工作后将任务标记为完成，项目负责人可看到更新。

## 5. MVP 范围

### P0

- 邮箱和密码登录；
- 创建、查看和归档项目；
- 邀请已有用户加入项目；
- 创建和查看任务；
- 修改任务状态；
- 管理员、编辑者和只读成员三种项目角色；
- 桌面端和移动端核心流程可用。

### P1

- 按负责人和状态筛选任务；
- 修改任务标题、负责人和截止日期；
- 查看项目操作记录。

### P2

- 邮件提醒；
- 任务评论；
- 文件附件。

## 6. 不在 MVP 范围内

- 甘特图和工时统计；
- 子任务及复杂依赖；
- 批量导入和导出；
- 自定义工作流；
- 与第三方平台集成；
- 原生移动应用；
- 多语言界面。

## 7. 成功指标

发布后前 30 天使用以下指标评估 MVP：

- 至少 70% 的新建团队能成功创建第一个项目和第一条任务；
- 核心流程“登录→进入项目→创建任务”的成功率不低于 95%；
- 创建任务操作的服务端错误率低于 1%；
- P0 功能不存在阻塞使用的已知缺陷。

## 8. 产品原则

- 优先减少完成核心任务所需的操作步骤；
- 权限和数据一致性优先于操作便利性；
- 首个版本保持固定、简单的任务状态，不支持用户自定义；
- 不用未经确认的高级功能增加核心页面复杂度。

## 9. 待决策事项

- 是否允许项目管理员将自己的管理员角色转移给他人；
- 归档项目的最长保留期限；
- P2 通知功能采用即时通知还是每日摘要。
